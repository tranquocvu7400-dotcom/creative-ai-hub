# Shop Intelligence Profile Schema (concept)

Mục đích: giúp AI nhận diện và tái tạo *vibe/style* phù hợp với từng shop khi tạo hình ảnh sản phẩm mới.

## 1. Shop Profile

Brand DNA, overall vibe, visual identity, palette và mức độ nhất quán/ngoại lệ của phong cách shop.

## 2. Category Profile

Những chuẩn thị giác riêng theo từng nhóm sản phẩm: mũ, áo, tote bag, crochet, embroidered apparel... Cùng một shop có thể có nhiều category style.

## 3. Listing Visual Profile

Cấu trúc gallery: số lượng ảnh, thứ tự ảnh, vai trò từng vị trí và storytelling. Role tham khảo: Hero, Detail, Lifestyle, UGC, Variation, Gift, Info.

## 4. Image Style Profile

Mỗi hình được phân tích độc lập theo role, vibe, phong cách nhiếp ảnh, ánh sáng, góc chụp, nền, bố cục, con người, props, màu sắc và cảm xúc.

## 5. Platform Profile

Yêu cầu và xu hướng trình bày phù hợp Amazon, Etsy, Shopify. Tách quy định chính thức khỏi những thực hành quan sát được.

## Nguyên tắc phân tích

Với mỗi kết luận cần ghi:
- Ảnh hoặc listing nguồn làm bằng chứng.
- Tần suất xuất hiện trong mẫu đã quan sát.
- Ngoại lệ, độ tin cậy và chỗ chưa chắc chắn.
- Phân biệt quan sát thực tế và suy luận của Agent.

## Cách áp dụng khi tạo ảnh

Brand DNA + Category Style + Image Role + Image Style + Product Accuracy + Platform Constraints + Visual References + Negative Constraints.

Đây là **conceptual schema**, chưa phải cấu trúc database hay contract JSON chính thức.
